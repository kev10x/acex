FAQ

Common questions

Does Acexen replace the marker?

No — it assists them. Every AI mark goes through your moderation queue before it's released. You review, adjust, or override any score. Think of Acexen as a highly consistent first-pass marker that handles the repetitive work.

Which AI models does it use?

Acexen works with OpenAI (GPT-4o, GPT-4o-mini, o3-mini) and Anthropic (Claude 3.5 Sonnet, Haiku). You choose the model per task type in the config file. Switching providers requires only changing one environment variable.

How accurate is the AI marking?

Accuracy depends heavily on rubric quality. With a well-specified rubric and clear mark allocation, Acexen typically agrees with a human marker within ±5% on total score. Strictness levels (very strict / strict / moderate / lenient) let you calibrate the AI's disposition to match your department's standards.

Can it handle scanned or handwritten submissions?

Yes. When PDF text extraction fails (scanned documents), Acexen automatically falls back to the vision API (GPT-4V or Claude Vision) to process the image. For handwriting, accuracy depends on legibility.

Does it work with Moodle?

Yes. The Moodle integration lets you pull assignments directly from your LMS and push grades back. Requires the Moodle REST API to be enabled on your instance.

What are the server requirements?

Node.js 18+, 2 GB RAM (4 GB recommended for large batches), and either SQLite (single server), MySQL, or PostgreSQL. A standard $10/month VPS handles most small-to-medium institutions comfortably.

How do I get started?

Clone the repository, copy .env.example to .env, add your database URL and AI API key, then run npm run setup && npm run dev. Full deployment instructions are in DEPLOYMENT.md. The managed hosting option means we handle all of this for you.
