# Answer Key Templates

This directory contains templates for creating answer keys (marking memorandums) that can be uploaded to MarkMate.

## Files

- **answer-key-template-structure.txt**: A plain text template with the exact structure to follow
- **ANSWER_KEY_TEMPLATE_GUIDE.md**: Detailed guide with examples and instructions

## How to Use

1. **Option 1: Use the Text Template**
   - Open `answer-key-template-structure.txt`
   - Copy the structure
   - Fill in your questions and answers
   - Save as a document

2. **Option 2: Create ODF Template**
   - Open LibreOffice Writer
   - Copy the structure from `answer-key-template-structure.txt`
   - Format it nicely (use headings, bold, etc.)
   - Save as `.odt` file
   - Use this template for future answer keys

3. **Upload to MarkMate:**
   - Go to Rubrics tab
   - Create new rubric
   - Enter each question as a criterion
   - Copy model answers into descriptions
   - Add levels based on marking schemes
   - The system will detect it as a memo automatically

## Template Features

- Clear structure for questions
- Model answer sections
- Marking scheme definitions
- Partial credit guidelines
- Examiner notes sections

## Tips

- Use keywords like "Marking Memorandum", "Model Answer", "Marking Scheme" to ensure detection
- Be specific about what earns full marks vs partial marks
- Include worked examples for calculation questions
- Define alternative acceptable answers where applicable
